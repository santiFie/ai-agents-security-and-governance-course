# Repositorios open-source para seguridad de IA

Lista de herramientas open-source y activamente mantenidas para probar, atacar y defender
sistemas de IA. URLs verificadas directamente (no acortadores) el 2026-08-10.

| Repositorio | Qué hace |
|---|---|
| [Azure/PyRIT](https://github.com/Azure/PyRIT) | Framework de red-teaming de IA de Microsoft. Permite armar playbooks de ataque, automatizar pruebas contra apps LLM y generar reportes — la misma herramienta que usa el equipo de AI Red Team de Microsoft. |
| [NVIDIA/garak](https://github.com/NVIDIA/garak) | Scanner de vulnerabilidades para LLMs. Apuntado a un modelo, prueba automáticamente jailbreaks, prompt injection, fuga de datos y salidas tóxicas. |
| [promptfoo/promptfoo](https://github.com/promptfoo/promptfoo) | Testing de prompts, agentes y pipelines RAG con chequeos de seguridad incorporados. Se integra directo en CI/CD. |
| [protectai/llm-guard](https://github.com/protectai/llm-guard) | Toolkit de Protect AI para sanitización de prompts, detección de PII y filtrado de contenido dañino — protección en tiempo de ejecución. |
| [NVIDIA/NeMo-Guardrails](https://github.com/NVIDIA/NeMo-Guardrails) | Guardrails basados en políticas para IA conversacional. Permite definir reglas y flujos de qué puede y no puede hacer un asistente. |
| [meta-llama/PurpleLlama](https://github.com/meta-llama/PurpleLlama) | Suite de seguridad de Meta — Llama Guard para clasificación de input/output y herramientas de detección de jailbreak. |
| [Trusted-AI/adversarial-robustness-toolbox](https://github.com/Trusted-AI/adversarial-robustness-toolbox) | Librería de IBM para ML adversarial clásico — evasión, poisoning, extracción de modelos y defensas. Clave si trabajás con visión o modelos tabulares. |
| [Giskard-AI/giskard](https://github.com/Giskard-AI/giskard) | Evaluación y testing open-source para sistemas de ML y LLM — detecta sesgo, fuga de datos y problemas de robustez. |
| [corca-ai/awesome-llm-security](https://github.com/corca-ai/awesome-llm-security) | Índice curado por la comunidad de herramientas, papers e investigación de seguridad en LLMs. |
| [greshake/llm-security](https://github.com/greshake/llm-security) | El repo de investigación original sobre prompt injection indirecta — la clase de ataque que cualquiera que construya agentes necesita entender. |
